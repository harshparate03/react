Product REST API
Create a Node.js and Express.js server with the following endpoints:
- GET /products: Return a hardcoded array of product objects containing id, name, 
and price.
- POST /products: Add a new product from the request body to the array.
Requirements:
1. Use express.json() middleware.
2. Return JSON responses.
3. Validate the product data.
4. Test both endpoints using Postman.
